Module episode

Expand description

Bounded normalization of redacted episode-analysis artifacts. Bounded, read-only normalization of redacted episode-analysis artifacts.

The auditor consumes reports produced by the repository’s existing offline analyzers. It never imports raw prompts, source, tool arguments, or tool outputs, and it preserves unavailable measurements as null.
